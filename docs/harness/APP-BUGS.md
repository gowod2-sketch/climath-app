# 하네스 감사가 찾아낸 앱 버그

**이 버그들은 하네스 스프린트가 만든 것이 아닙니다.** 기존 콘텐츠(수열의 극한 단원)에 이미 있던 것을 정합성 감사가 찾아냈습니다. 현재 라이브(math-tip-popup.netlify.app)에 나가 있습니다.

**둘 다 `build.py`가 exit 0을 냅니다.** 그래서 여태 아무도 몰랐습니다.

## 버그 1 — 팁 링크가 조용히 죽는다

**증상:** 개념 03 p2, 개념 04 p1에서 화면에 `[[∑val|급수의 합]]`이 **대괄호째** 나오고 팝업이 뜨지 않습니다.

**원인:** `build.py`의 `prose()`가 링크를 파싱하기 **전에** `syms()`를 돌립니다.

```python
def prose(t):
    t = syms(t)                    # ← 여기서 'sumval' → '&#8721;val'
    t = re.sub(r'\[\[([a-z0-9_]+)\|([^\]]+)\]\]', link, t)   # ← 더 이상 매치 안 됨
```

`sum`이 `SYM` 테이블에 있어서, 팁 id `sumval`이 `&#8721;val`로 바뀝니다. 그러면 링크 정규식의 `[a-z0-9_]+`에 걸리지 않아 `<span class="term" data-t="...">`가 **생성되지 않습니다.**

**왜 빌드가 못 잡나:** 링크 검사가 `data-t="([a-z0-9_]+)"`를 찾아 tip 파일 존재를 대조하는데, 애초에 `data-t`가 안 만들어졌으니 검사 대상에 없습니다. "없는 팁 id"로도 안 걸립니다.

**영향 범위:** 팁 id에 `SYM` 문자열(`sum`, `oo`, `alpha`, `beta`, `...`, `->`, `-oo`, `<=`, `>=`, `!=`, `+-`)이 부분 문자열로 들어간 모든 링크. 현재 `sumval` 하나가 해당되고 개념 03·04에서 쓰입니다.

**탐지 명령** (빌드 후 실행):
```bash
python3 -c "
import json; d=json.load(open('mathuit/content-data.json'))
print([(p['no'],f) for p in d['pages'] for f in ('p1','p2') if '[[' in p.get(f,'')] or '죽은 링크 없음')"
```

**수정 방향 (제안, 미적용):** `prose()`에서 링크를 먼저 추출해 자리표시자로 빼두고 `syms()`를 돌린 뒤 되돌리거나, `syms()`가 `[[...|` 안쪽을 건드리지 않게 합니다. 렌더링 전반에 영향이 가는 변경이라 적용하지 않았습니다.

## 버그 2 — 수식 안 기호 약어가 엔티티 코드로 노출

**증상:** 개념 03·06·07·08·10의 수식에서 `∑`가 아니라 `&#8721;` 이라는 글자가 그대로 보입니다. 본문에서는 `-oo`가 `&minus;`로 깨집니다(개념 01 p2, `diverge`·`oscillate`의 oneline).

**원인:** `mathify()`가 `syms()`를 먼저 돌린 뒤 결과를 **문자 단위로** 순회합니다.

```python
def mathify(t):
    t = syms(t)            # 'sum' → '&#8721;'
    ...
    if c.isdigit() or c in '+=()[]|,.<>/&#;':
        out.append('<span class="m">%s</span>' % c)   # & # 8 7 2 1 ; 이 각각 span 으로
```

`&#8721;`의 각 문자가 개별 span에 갇혀 HTML 엔티티로 해석되지 못합니다. `index.html:258`이 `innerHTML`로 넣으므로 화면에는 `&#8721;`이 문자 그대로 나옵니다.

**수정 방향 (제안, 미적용):** `mathify()`가 `syms()` 결과의 엔티티(`&...;`)를 하나의 토큰으로 인식해 통째로 통과시키면 됩니다.

## 부수 확인 — `$$` 수식 개수

`build.py`는 `re.search`로 **첫 번째** `$$`만 찾습니다. 수식이 2개여도 빌드는 통과하고, 두 번째 수식은 p2에 원문 그대로 노출됩니다. 현재 위반 콘텐츠는 없지만, "빌드가 막아줄 것"이라 기대하면 안 됩니다.

## 그 밖에 (버그 아님, 참고)

- `mathuit/content/_README.md`의 curve 표에 **행 이름이 뒤바뀐 상태**가 남아 있습니다 — "위에서 수렴 = `60 + 80/n`"은 반대입니다. 하네스 스킬은 정정됐지만 사람이 읽는 안내서는 그대로입니다.
- `SYM` 테이블의 그리스 문자가 `alpha`, `beta` 둘뿐입니다. 삼각함수 단원(`docs/04`)에는 θ가 필요합니다. `('theta','&#952;')` 한 줄 추가로 해결되고, `theta`에는 기존 항목이 부분 문자열로 포함되지 않아 위치는 무관합니다.
