## 1️⃣ 급수의 정의

### 급수(Series)란?
수열의 항들을 차례로 더한 것을 **급수**라고 한다.

$$\sum_{n=1}^{\infty} a_n = a_1 + a_2 + a_3 + \cdots$$

### 부분합(Partial Sum)
처음 n개 항의 합을 **부분합** $S_n$이라 한다:

$$S_n = \sum_{k=1}^{n} a_k$$

---

## 2️⃣ 등비급수 (Geometric Series)

### 형태
첫 항 $a$, 공비 $r$인 등비수열의 급수:

$$\sum_{n=1}^{\infty} ar^{n-1} = a + ar + ar^2 + \cdots$$

### 수렴/발산 판정

| 공비 $r$ | 수렴 여부 | 합 |
|---------|---------|-----|
| $\|r\| < 1$ | **수렴** | $\frac{a}{1-r}$ |
| $\|r\| \geq 1$ | **발산** | - |

#### 예시
- $1 + \frac{1}{2} + \frac{1}{4} + \cdots = \frac{1}{1-\frac{1}{2}} = 2$ ✓ (수렴)
- $1 + 2 + 4 + 8 + \cdots$ ✗ (발산)

---

## 3️⃣ 등급수 (Telescoping Series)

### 형태
$(a_1 - a_2) + (a_2 - a_3) + (a_3 - a_4) + \cdots$

### 특징
- 대부분의 항이 소거됨
- 부분합: $S_n = a_1 - a_n$
- $\lim_{n \to \infty} a_n = L$이면, 급수는 $a_1 - L$로 수렴

#### 예시
$$\sum_{n=1}^{\infty} \frac{1}{n(n+1)} = \sum_{n=1}^{\infty} \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1$$

---

## 4️⃣ 급수 판정법 (초급)

### 발산 판정법 (Divergence Test)
$$\lim_{n \to \infty} a_n \neq 0 \Rightarrow \sum a_n \text{ 발산}$$

**주의**: $\lim a_n = 0$이어도 급수가 발산할 수 있음

### 비교 판정법 (Comparison Test)
$0 \leq a_n \leq b_n$일 때:
- $\sum b_n$ 수렴 $\Rightarrow$ $\sum a_n$ 수렴
- $\sum a_n$ 발산 $\Rightarrow$ $\sum b_n$ 발산

---

## 💡 팁 (Tip)

### 급수 판정 흐름도
```
급수 ∑aₙ이 주어졌을 때

1. lim aₙ = 0인가? → 아니오 → 발산
   ↓ 예

2. 등비급수 형태인가? → 예 → |r| < 1이면 수렴
   ↓ 아니오

3. 등급수 형태인가? → 예 → 소거하여 판정
   ↓ 아니오

4. 비교 가능한 급수가 있나? → 비교 판정법 사용
```

## 🎬 풀이 예제

### 문제 1
$\sum_{n=1}^{\infty} \frac{n}{n^2 + 1}$의 수렴/발산 판정

**풀이**:
- $\lim_{n \to \infty} \frac{n}{n^2 + 1} = \lim_{n \to \infty} \frac{1}{n + \frac{1}{n}} = 0$ ✓
- 발산 판정법만으로는 판정 불가
- 비교: $\frac{n}{n^2 + 1} > \frac{n}{n^2 + n^2} = \frac{1}{2n}$
- $\sum \frac{1}{2n}$ 발산 (조화급수) → **원급수 발산**

### 문제 2
$\sum_{n=1}^{\infty} 3 \cdot \left(\frac{2}{3}\right)^{n-1}$의 합

**풀이**:
- 등비급수, $a = 3$, $r = \frac{2}{3}$
- $|r| = \frac{2}{3} < 1$ → 수렴
- $S = \frac{3}{1 - \frac{2}{3}} = \frac{3}{\frac{1}{3}} = 9$
