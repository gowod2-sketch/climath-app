## 1️⃣ 삼각함수의 덧셈정리

### $\sin(A \pm B)$ 공식
$$\sin(A + B) = \sin A \cos B + \cos A \sin B$$
$$\sin(A - B) = \sin A \cos B - \cos A \sin B$$

### $\cos(A \pm B)$ 공식
$$\cos(A + B) = \cos A \cos B - \sin A \sin B$$
$$\cos(A - B) = \cos A \cos B + \sin A \sin B$$

### $\tan(A \pm B)$ 공식
$$\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$$
$$\tan(A - B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$$

---

## 2️⃣ 배각공식 (Double Angle)

### $\sin 2A$ 공식
$$\sin 2A = 2\sin A \cos A$$

### $\cos 2A$ 공식 (3가지 형태)
$$\cos 2A = \cos^2 A - \sin^2 A$$
$$\cos 2A = 2\cos^2 A - 1$$
$$\cos 2A = 1 - 2\sin^2 A$$

### $\tan 2A$ 공식
$$\tan 2A = \frac{2\tan A}{1 - \tan^2 A}$$

### 유도 예시
**$\sin 2A$ 유도**:
$$\sin 2A = \sin(A + A) = \sin A \cos A + \cos A \sin A = 2\sin A \cos A$$

**$\cos 2A$ 유도**:
$$\cos 2A = \cos(A + A) = \cos A \cos A - \sin A \sin A = \cos^2 A - \sin^2 A$$

---

## 3️⃣ 반각공식 (Half Angle)

### 반각공식 유도
$\cos 2A = 1 - 2\sin^2 A$에서:
$$\sin^2 A = \frac{1 - \cos 2A}{2}$$
$$A \to \frac{\theta}{2}$로 치환하면:
$$\sin^2 \frac{\theta}{2} = \frac{1 - \cos \theta}{2}$$

### 반각공식 정리
$$\sin^2 \frac{\theta}{2} = \frac{1 - \cos \theta}{2}$$
$$\cos^2 \frac{\theta}{2} = \frac{1 + \cos \theta}{2}$$
$$\tan^2 \frac{\theta}{2} = \frac{1 - \cos \theta}{1 + \cos \theta}$$

---

## 4️⃣ 곱을합으로, 합을곱으로

### 곱을 합으로 변환
덧셈정리에서:

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$
$$\cos A \sin B = \frac{1}{2}[\sin(A+B) - \sin(A-B)]$$
$$\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$$
$$\sin A \sin B = -\frac{1}{2}[\cos(A+B) - \cos(A-B)]$$

### 합을 곱으로 변환
합의 형태를 $\frac{p+q}{2}$, $\frac{p-q}{2}$로 치환:

$$\sin p + \sin q = 2\sin \frac{p+q}{2} \cos \frac{p-q}{2}$$
$$\sin p - \sin q = 2\cos \frac{p+q}{2} \sin \frac{p-q}{2}$$
$$\cos p + \cos q = 2\cos \frac{p+q}{2} \cos \frac{p-q}{2}$$
$$\cos p - \cos q = -2\sin \frac{p+q}{2} \sin \frac{p-q}{2}$$

## 💡 팁 (Tip)

### 공식 암기 전략

#### 1단계: 핵심만 기억
- **$\sin(A+B)$**: 신신코코 (신-신코 + 코-신)
- **$\cos(A+B)$**: 코코신신 (코-코 - 신-신)
- **배각**: 사인은 2배, 코사인은 여러 형태

#### 2단계: 부호 규칙
- $\sin(A+B)$ → +
- $\sin(A-B)$ → -
- $\cos(A+B)$ → -
- $\cos(A-B)$ → +

#### 3단계: 적용 흐름도
```
문제 분석
  ↓
어떤 공식을 쓸까?
  - 덧셈? 배각? 반각?
  - 곱→합? 합→곱?
  ↓
공식 적용
  ↓
정리 및 검산
```

## 🎬 풀이 예제

### 문제 1
$\sin 75°$를 구하시오.

**풀이**:
$$\sin 75° = \sin(45° + 30°)$$
$$= \sin 45° \cos 30° + \cos 45° \sin 30°$$
$$= \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2}$$
$$= \frac{\sqrt{6} + \sqrt{2}}{4}$$

### 문제 2
$\cos 2\theta = \frac{3}{5}$일 때, $\cos \theta$를 구하시오. (단, $0 < \theta < \frac{\pi}{2}$)

**풀이**:
$$\cos 2\theta = 2\cos^2 \theta - 1 = \frac{3}{5}$$
$$2\cos^2 \theta = \frac{8}{5}$$
$$\cos^2 \theta = \frac{4}{5}$$
$$\cos \theta = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$$ (양수)

### 문제 3
$\sin 3x + \sin x = 0$을 풀이하시오. (단, $0 \leq x < 2\pi$)

**풀이**:
$$\sin 3x + \sin x = 2\sin \frac{3x+x}{2} \cos \frac{3x-x}{2} = 0$$
$$2\sin 2x \cos x = 0$$
$$\sin 2x = 0 \text{ 또는 } \cos x = 0$$
$$x = 0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}$$
