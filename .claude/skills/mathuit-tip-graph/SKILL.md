# 팁개념 그래프·스토리보드 설계

팁 팝업의 그래프는 **n = 1..12 의 점 12개를 찍는 산점도로 고정**이다. 형식을 고를 수 없다.

## 좌표계가 뒤집혀 있다

`curve`는 수학 값이 아니라 **화면 y좌표**를 만드는 식이다. **값이 작을수록 위쪽**이다.

```
y = 10   ← 화면 맨 위
y = 160  ← 화면 맨 아래
```

그래서 "무한대로 발산"은 값이 커지는 식이 아니라 **작아지는** 식이다. 이 반전을 놓치면 그래프가 위아래 반대로 나오고, 학생은 수렴을 발산으로 배운다.

**검산 방법:** 식에 n=1과 n=12를 대입해 두 값을 비교하라. 의도한 방향인지 눈으로 확인한 뒤 확정한다.

## curve 카탈로그

| 거동 | 식 | n=1 → n=12 |
|------|-----|-----------|
| 위에서 한 값에 수렴 | `60 + 80/n` | 140 → 66.7 (아래로 내려와 60에 접근) |
| 아래에서 한 값에 수렴 | `150 - 90/n` | 60 → 142.5 (위로 올라가 150에 접근) |
| 무한대로 발산 | `152 - 10.5*n` | 141.5 → 26 (계속 위로) |
| 진동 (두 값 왕복) | `n%2==1 ? 136 : 64` | 두 값 반복 |
| 등비 감쇠 | `150 - 90*0.72**(n-1)` | 60 → 148 |
| 부분합이 S에 수렴 | `160 - 100*(1 - 0.5**n)` | 110 → 60 |

**상수는 화면에 담기게 조절한다.** curve는 거동을 보여주는 도구지 정확한 함숫값이 아니다. 대략 10~160 범위에 들어오면 된다.

## 보조선과 라벨

```
## graph

curve: 60 + 80/n
lines: [60]
label: y = L
label_at: right
```

| 항목 | 뜻 |
|------|-----|
| `lines` | 점선 보조선의 y좌표 목록. `[60]` 또는 `[64, 136]` |
| `label` | 보조선 옆 설명 |
| `label_at` | `right` / `left` / `center` |

## 스토리보드

```
## steps

| show | line | label | caption |
|------|------|-------|---------|
| 3  |   |   | a₁, a₂, a₃ 을 순서대로 찍어요. |
| 12 |   |   | n이 커질수록 점들이 한 값으로 몰려가요. |
| 12 | v |   | 다가가는 값을 점선 y = L 로 표시해요. |
| 12 | v | v | a_n은 L에 한없이 가까워져요. |
```

| 칸 | 뜻 |
|----|-----|
| `show` | 점을 몇 번째까지 보여줄지 (누적 개수, 정수) |
| `line` | 보조선 켜기 — `v` |
| `label` | 라벨 켜기 — `v` |
| `caption` | 그 스텝의 한 줄 설명 (25자 내외, 구어체) |

**2~4컷을 지켜라.** `build.py`가 5개 초과를 거부하고, 1초 간격 자동 재생이라 5컷이면 학생이 손을 떼기 전에 다 못 본다.

**누적으로 쌓아라.** 점 → 점 더하기 → 보조선 → 라벨 순으로 하나씩 켜야 시선이 따라간다. 한 컷에 여러 요소를 동시에 켜면 뭘 봐야 할지 모른다.

## 산점도로 표현할 수 없는 용어

이 형식은 **수열**을 전제한다. 모든 수학 용어가 여기 맞지는 않다.

| 표현 가능 | 예 |
|----------|-----|
| 극한으로 정의되는 개념 | 자연상수 e — `(1+1/n)^n`의 극한이므로 산점도로 정확히 표현된다 |
| 수렴·발산·진동하는 수열 | 등비수열, 부분합 |

| 표현 불가 | 예 |
|----------|-----|
| 연속함수의 순간변화율 | 미분계수, 도함수 |
| 각의 항등식 | 삼각함수 덧셈정리, 배각공식 |

**표현이 안 되는 용어에 그럴듯한 curve를 지어내지 마라.** 틀린 그림은 없는 그림보다 나쁘다 — 학생이 개념을 시각적으로 잘못 각인한다. 이런 용어를 만나면 파일을 만들지 말고 다음을 보고하라:

1. 용어 id와 산점도로 표현이 안 되는 이유
2. 대안 — 그래프 형식 확장이 필요한지, 팁 대신 개념 본문의 평문으로 설명할지

이 판단은 `docs/03_지수로그함수_미분.md`, `docs/04_삼각함수_덧셈정리.md` 작업에서 실제로 걸린다. 수열의 극한 단원(concept c01~c12)과 달리 이 두 단원은 대부분의 용어가 수열이 아니다.
