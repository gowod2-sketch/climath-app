# Mathuit

미적분2 "수열의 극한" 개념을 유리판처럼 좌우로 밀어 읽는 PWA.
본문의 파란 용어를 누르면 하단에서 바텀시트가 올라오고, 단계별 그래프가 자동 재생됩니다.

라이브: https://math-tip-popup.netlify.app
편집기: https://math-tip-popup.netlify.app/editor.html

## 개념을 고치는 방법 (셋 중 아무거나)

### 1. 편집기에서 (가장 쉬움, 권장)

https://math-tip-popup.netlify.app/editor.html 를 엽니다.

개념이든 팁개념이든 **기존 파일을 골라 불러오고, 고치고, "저장하고 배포"를 누르면 끝**입니다.
GitHub에 자동으로 커밋되고 Netlify가 2~3분 안에 배포합니다. 터미널도 git도 필요 없습니다.

새 개념은 "새로 작성"을 누르고 파일명만 정해주면 됩니다 (예: `c13.md`).

> 이 자동 저장은 Netlify 환경변수 `GITHUB_TOKEN`이 있어야 동작합니다.
> 없으면 편집기가 마크다운을 만들어 보여주니 복사해서 GitHub에 붙여넣으면 됩니다.

### 2. GitHub 웹에서 직접

`mathuit/content/concept/` 또는 `mathuit/content/tip/` 의 `.md` 파일을 열고
연필 아이콘을 눌러 고친 뒤 커밋하면 자동 배포됩니다.

### 3. 로컬에서

`.md` 파일을 편집기(VS Code, Obsidian, 메모장 등)로 고치고:

```bash
python3 build.py     # 문법 검사 + index.html에 주입
git add -A && git commit -m "개념 수정" && git push
```

## 콘텐츠 문법

문법은 `content/_README.md`에 정리돼 있습니다. 요점만:

- 용어 링크: `[[converge|수렴]]` — 파랗게 표시되고 누르면 팝업
- 수식: `$$ lim_{n->oo} a_n = L $$` — 변수 이탤릭, lim·숫자 로만은 자동 변환
- 기호 약어: `->` `oo` `-oo` `<=` `>=` `!=` `+-` `sum` `...` `alpha` `beta`

## 배포

**`main`에 push하면 Netlify가 알아서 빌드하고 배포합니다.** 편집기에서 저장해도 같은 경로를 탑니다.

빌드는 이렇게 돕니다.

1. `python3 build.py` — `content/`의 md 문법을 검사하고 `index.html`의 `/*DATA:BEGIN*/` 블록에 주입
2. 통과하면 `dist/`에 배포 파일을 모아 게시

**검사에 실패하면 배포가 멈춥니다.** 없는 팁개념 id를 참조하는 등 문제가 있으면 빌드가 exit 1로 끝나고, 라이브 사이트는 이전 상태 그대로 유지됩니다.

## 앱 조작

| 동작 | 결과 |
|---|---|
| 좌우로 밀기 / 화면 끝 탭 | 페이지 넘기기 |
| 파란 용어 탭 | 팁개념 팝업 열기 (여러 개 쌓임) |
| 흐린 배경 탭 | 팝업 한 겹만 닫기 |
| 흐린 배경 밀기 | 열린 팝업 전부 닫기 |
| 두 손가락 오므리기/벌리기 | 확대·축소 (최대 3.2배) |
| 확대 상태에서 한 손가락 | 이동(팬) |
| 더블탭 | 확대 / 원래대로 |
| 길게 누르기 | 필기 모드 진입 |
| ✏ 버튼 | 필기 모드 켜기/끄기 |

## 파일

| 경로 | 역할 |
|---|---|
| `index.html` | 앱 본체. `/*DATA:BEGIN*/` 블록은 build.py가 덮어씁니다 — 직접 고치지 마세요 |
| `editor.html` | 웹 편집기 |
| `netlify/functions/save-content.js` | 편집기의 저장을 GitHub 커밋으로 바꿔주는 서버리스 함수 |
| `sw.js` | 서비스워커. **내용을 고치면 캐시명 `mathtip-vN`을 반드시 +1** |
| `manifest.webmanifest` | PWA 매니페스트 |
| `icon.png` | 앱 아이콘 (오선지 위 8분음표 두 개, 미→솔) |
| `logo.svg` | 아이콘 벡터 원본 (배포되지 않음) |
| `_headers` | 캐시 헤더 |
| `content/` | 개념·팁개념 원고 — **여기가 콘텐츠 원본입니다** |
| `build.py` | md 검사기 + index.html 주입기 |
| `tools/export_to_md.py` | (일회성) 옛 하드코딩 데이터를 md로 역추출한 도구 |

## 디자인 규칙 (바꾸지 말 것)

- 페이지 전환은 슬라이드, 기본 340ms. 롤링·페이지컬 금지
- 라이트 모드 고정. 인디고 `#4C5FD5`, 바이올렛 `#7B5CE6`, 코랄 `#F2653E`, 잉크 `#1B2033`
- 수식은 배경 박스 없이 검정 볼드 세리프
- 용어에 박스·밑줄·포커스 아웃라인 금지. 강조는 색과 굵기만
- 용어 노출 페이드: 1~20회 인디고 볼드→검정, 21~40회 무강조+팝업 유지, 41회~ 비활성
- 필기 모드에서는 스와이프와 용어 터치가 잠김
